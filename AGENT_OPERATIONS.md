# Agent Operations


## Roles
Readiness scanner classifies work; worker implements bounded scope; monitor detects conflicts; integration validator records evidence.

## Before Work
Read authoritative documents, establish traceability and scope, classify sensitive data, and name validation.

## Parallel Work
Do not concurrently change contracts, schemas, manifests, deployment files, or status artifacts without an integration owner.

## Validation Debt
Record known out-of-scope failures in docs/orchestrator/VALIDATION_DEBT.md; current-task failures remain blocking.

## Handoff
Record objective, files, evidence, blockers, ownership, and follow-up work.

## Project-Specific Operations
Follow documented safety and ownership boundaries for database-server.
